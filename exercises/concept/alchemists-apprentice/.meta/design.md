# Design

## Goal

Introduce the student to Zig's basic building blocks: named values, functions and arithmetic. This is the first exercise on the syllabus, so it assumes nothing about Zig and only that the student has programmed before.

## Learning objectives

- Know how to bind a name with `const` and with `var`.
- Know that Zig is statically typed, and that a type is usually inferred but can be written after a colon.
- Know how to declare a function with typed parameters and a return type.
- Know that a declaration must be marked `pub` to be visible outside its file.
- Know the arithmetic operators `+`, `-`, `*`, `/` and `%`.
- Know how to call one function from another.

## Out of scope

- Integer widths, signedness and overflow.
- Floating point numbers.
- `@import` and the standard library.
- Control flow of any kind.
- `comptime_int` and type coercion.

## Concepts

- `basics`: binding names with `const` and `var`, declaring and calling functions, arithmetic operators, `pub`, `//` comments.

## Prerequisites

None. This is the root of the syllabus and the only exercise with an empty `prerequisites` array.

## Analyzer

No analyzer support.
